# ADR-0001 · 双通道架构：确定性规则 + LLM 语义审查

- 状态：已采纳（2026-10-14）
- 决策人：周宗正（起草）、余俊辉（复核）
- 关联：总档 §3、`specification.md` §2/§5

## 背景

单一手段都不够：
- 纯确定性规则：可复现，但只认写好的模式（漏报），正则无上下文（误报）；
- 纯 LLM 审查：覆盖广，但不可复现、会编、给定结果不可靠。

课程同时要求"可复核"与"有深度的语义审查"。

## 决策

采用双通道：**A 确定性规则引擎**（执行层，完全不放 AI）+ **B LLM 语义审查**
（B1 对 A 命中做上下文复核、B2 对敏感区域独立扫描），融合层用**确定性规则**合并两侧，
B 的结论天花板为「待复核」。

## 理由

- 可复现的部分（A）与不可复现的部分（B）物理隔离：证据落盘时 B 的 prompt/响应/哈希全部留痕；
- 融合规则不靠 LLM 判决——LLM 提疑、规则钉证据（ADR-0004），把"语义发现"重新锚回"机械可验证"；
- B 可失效（无模型即跳过），A 永不受影响（降级是硬要求）。

## 后果

- 正面：既有确定性基线（靶场 84 判点全一致），又不放弃召回扩展；
- 负面：B 通道引入网络依赖与非确定性，报告中必须标注"B 通道运行/未运行"与模型版本；
- 反面约束：任何"B 单独说了算"的输出都被禁止。

## 替代方案（被否）

- 只用规则：召回不足，且课程要求语义审查深度；
- 只用 LLM：不可复现、不可对抗，直接被证据纪律否掉；
- 规则+LLM 自由混合（LLM 直接改结论）：无法审计责任链，否。
