### Finding 模板（六要素）

| 字段 | 填写要求 |
|------|----------|
| 目标版本 | 规则包版本 + RUN id |
| 前置条件 | 样本构造方式、运行环境 |
| 最小复现 | 一条命令 + 样本哈希 |
| 实际 / 预期 | 分开写，不合并 |
| 证据 | 报告坐标 + 原文片段 + 截图/日志 |
| 影响 | 是漏报、误报、档位错，还是措辞升级 |
| 修复回归 | 我方修复后由对方复跑同一命令 |
