| 字段 | 填写要求 |
|------|----------|
| 目标版本 | 规则包版本 + RUN id |

| 证据 | 报告坐标 + 原文片段 + 截图/日志 |
| 影响 | 是漏报、误报、档位错，还是措辞升级 |
| 修复回归 | 我方修复后由对方复跑同一命令 |
