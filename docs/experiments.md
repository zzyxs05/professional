# experiments · 实验卡与逐次数据【review / O4】

> 允许并保留负结果。每卡：假设 → 设置 → 逐次数据 → 结论（含失败与成本）。

## 实验 1：靶场真值一致性（核心质量门）

**假设**：双通道单通道基线（A 通道全量规则）在 6 个标定样本上与真值 100% 对齐，
且零 FP、零噪声——"好的安静、坏的检出"同时成立。

**设置**：`lab/apks/` 6 样本 × 14 规则 = 84 判点；判罚口径 ADR-0006；
脚本 `scripts/truth_check.py`（全确定性，不靠 AI 判）。

**逐次数据**：

| 轮次 | 变更 | 结果（84 判点） | 硬错分解 |
|------|------|-----------------|----------|
| R1 | 首跑（bad03） | 3/7 规则命中（异常少） | 定位：`app_files` 路径切分 bug（自有代码判空） |
| R2 | 修复 app_files 后 bad03 | 14/14 | 0/0/0 |
| R3 | 全量 6 样本 | **84/84** | FP 0 / 漏检 0 / 档位错 0 / 噪声 0 |
| R4 | registry 敏感 API 模式修正（类级模式去 `->`）后回归 | **84/84**（保持） | 0/0/0/0 |

**结论**：假设成立。边界补充：R1 的定位耗时证明"规则命中数突变"是最有价值的自检信号——
已将其固化为 truth_check 的偏差明细输出。

**成本口径**：单样本全程（解码 5s + 规则 <1s + 报告 <1s）≈ 6s；全量回归 ≈ 2 分钟；零 LLM 调用。

## 实验 2：AXML 自研直读的正确性对照（合成夹具）

**假设**：自研解析器对两种 StringPool 编码（UTF-16 / UTF-8）均正确。

**设置**：`tests/fixtures/axml_builder.py` 合成 AXML → 解析 → 断言 6 组；
真实 6 样本抽查（对照 apktool 重建文本）。

**逐次数据**：

| 轮次 | 发现 | 处置 |
|------|------|------|
| R1 | 合成夹具暴露 UTF-8 模式**双长度字节**（utf16_len+utf8_len）解析错位（"manifest"→"manifes"） | 修复；真样本为 UTF-16 池故此前未暴露——**负结果**：真实样本未能覆盖该分支 |
| R2 | 修复后 6/6 夹具测试通过 + 全样本回归一致 | 结论：两种编码均正确 |

**结论**：合成夹具补上了真实样本覆盖不到的分支，验证了"不依赖真实 APK 的测试"的独立价值。

## 实验 3：确定性复现（A-09）

**设置**：bad02 连续运行两次（解码缓存预热后），归一化 run_id/证据 ID 逐字段比较。

**数据**：两次 `report.json` 归一化后深度相等（含结论、档位、定位、覆盖声明）。

**结论**：确定性路径（A 通道）复现成立；B 通道未运行（无模型），不进复现论断。

## 实验 4：通道 B 真实模型连测（已完成 2026-10-14/15）

**设置**：`key.txt` 配置真实模型（mimo-v2.6-flash，OpenAI 兼容端点 + 推理模型）；
B1 逐命中复核 + B2 敏感区扫描；判分用同一真值一致性脚本（B 开启口径）。

**逐次数据**：

| 轮次 | 发现 | 处置 | 结果 |
|------|------|------|------|
| R1 | B1 把示例凭据判"上下文无害"降级（越权判真伪）；钉证据把"实体存在"当"断言证实"造成假证据式升级（bad02 R-B-001）；B2 产出推测型/复述型 claim | 提示词 v0.2/v0.3 + 钉证据 v2 严格化（规则映射+实体核对） | bad02 恢复「已确认 2」 |
| R2 | B1 误降级 R-MAN-05（证据片段只截起始行）；R-MAN-01 映射缺"未设置"变体；摘要缺组件属性导致 good02 出现事实错误的疑点 | 片断完整化 + 三组 AND 匹配 + 摘要补全（含 protectionLevel 符号名） | 该轮快照清零；**最终批次仍有 9 条未钉疑点**（B2 输出有运行间波动，见 release I-6） |
| R3 | 最终全量（B 开启） | — | **84/84，硬错 0，噪声 0** |

**成本口径**：单样本 LLM 调用 = 1（连通探测）+ N_命中规则（B1）+ 1（B2）；
bad03 最高 9 次调用 ≈ 70s；good02 最低 2 次 ≈ 15s；预算上限 30 次/run，无一触顶。

**结论**：
1. B 通道在真实模型下**未破坏**确定性基线（84/84 保持），B1 复核逐条引用规则口径判定；
2. 本轮 B 侧疑点**全部停留在「待复核·未钉」**，未转化为任何新结论——即**B 的召回增量在标定样本上未被激活**
   （样本已被 A 全覆盖；疑点存在，但不构成新发现），其增量价值需 B 与规则冲突的新样本验证（列入下一步）；
3. 暴露的 6 项 B 通道缺陷全部通过"契约对齐"方式修复（记 `changes.md`），无一为样本特判。

## 实验 5：B3 六合一汇总报告（已完成 2026-10-15）

**设置**：`cli.py summary` 收集 6 样本最新 RUN → 结构化摘要 → 模型生成（≤900 字）。
**数据**：首次生成模型自行加总算错（18 处 vs 实际 17）；改为程序提供统计、模型只许引用后，
数字全对；总耗时 ≈ 26s。
**结论**：LLM 文本生成中"数字统计"必须由确定性程序提供（或强制引用），否则出现静默算错——
这是"LLM 提疑、规则钉证据"原则在报告生成环节的同类应用。

## 实验 6：数据源实现 A/B 对照（EXP-6，2026-11-11 实跑）

**技术决策**：ADR-0002（四层数据源分层、各自独立降级）。协议见 `docs/experiment-protocol.md`，
真实运行输出见 `review/exp_datasource_ab.json`，采集脚本 `scripts/exp_datasource_ab.py`。

**假设**：去掉 apktool 的零依赖弱模式，在靶场上应保持与强模式相同的**样本级检出结论**，
代价只体现在证据强度（档位上限）与定位精度上。

**设置**：A 组 = `smali_src` 强模式，B 组 = `dex_strings` 弱模式；6 个自建样本（1 正例 bad03 + 5 安静点）；
只跑 `R-CODE-01`；每方法预热 1 次 + 正式计时 5 轮；规则包 0.1.3；通道 B 未启用、零网络、零模型调用；
解码缓存复用，解码耗时不计入计时。

**逐次数据**（命中数 / 耗时中位数 ms，取自结果 JSON）：

| 样本 | A 强模式 | B 弱模式 | 样本级检出一致 | 备注 |
|------|----------|----------|:--------------:|------|
| bad01 | 0 / 76.094 | 0 / 22.312 | ✅ | 真值 `EXPECTED_SILENT` |
| bad02 | 0 / 78.953 | 0 / 23.665 | ✅ | 安静点 |
| **bad03** | **3 / 78.621** | **0 / 22.533** | ❌ | 唯一正例，真值 `EXPECTED_HIT:CONFIRMED` |
| bad04 | 0 / 73.620 | 0 / 30.987 | ✅ | 诱导对抗样本 |
| good01 | 0 / 98.252 | 0 / 28.224 | ✅ | 安静点 |
| good02 | 0 / 91.692 | 0 / 29.431 | ✅ | 边界陷阱样本 |

**汇总**：A 检出 1/6、B 检出 0/6、检出一致 5/6；A 跨样本耗时中位 **78.787 ms**、B **25.944 ms**（A ≈ 3.0×）；
所有样本 `hits_stable_across_rounds = true`（5 轮命中数无波动）；6 个样本解码缓存均可用，A 组全部真实运行。

**结论（假设被否定，负结果保留）**：

1. 弱模式在唯一正例 bad03 上**漏检**；5 个安静点上两组一致，说明差异不是随机噪声。
2. **归因不是「零依赖路径的固有召回损失」，而是实现缺陷**。bad03 的 dex 类型描述符里
   `Ldalvik/system/DexClassLoader;` **子串可见（substring_present = 1）**，但带 MUTF-8 长度前缀
   （实际值 `'\x1eLdalvik/system/DexClassLoader;'`），而 `r_code_01.py` 弱模式用
   `pat in ctx.dex.type_descriptors` 做精确集合成员判断（**exact_membership = 0**）。
   即：这条降级路径在现有样本上从未真正触发过，此前 84 判点未能暴露它——因为强模式优先返回，降级分支根本没走到。
   诊断事实随结果 JSON 落盘，不是推测。
3. 耗时差异主要来自 A 组构建 smali 文件索引（外部依赖带来的解析前置处理），不是规则计算本身；
   两组均不含 apktool 解码耗时，故**不构成端到端成本比较**。
4. 按「改规则 = 改版本」纪律，本轮**未修改任何规则、阈值或规则包版本**；缺陷记为 `docs/changes.md` **OBS-5**，
   作为 Change 候选。修复需 bump 版本 + 重跑 84 判点 + 前后差异回归，不在本实验内顺手改掉。

**成本口径**：单次全量 = 6 样本 × 2 方法 × (1 预热 + 5 计时) = 72 次采集；零模型调用、零网络、
不写 `evidence/`、不产生 RUN。结果 JSON 由脚本计算统计，文档结论只引用已落盘数据。

**边界**：只比一条规则的双源实现，不外推到其余 13 条；样本为自建合成，不外推真实应用；
详见 `docs/experiment-protocol.md` §7。

> 后续：OBS-5 已在规则包 **0.1.4** 修复，本实验数据保留为修复前快照（0.1.3），不改写；
> 修复后复测见下方实验 7。

## 实验 7：OBS-5 修复后的 A/B 复测（EXP-7，2026-11-11 实跑）

**背景**：实验 6 在 0.1.3 上暴露弱模式恒不命中，根因是 `core/dexscan.py::_read_string_at`
未剥离 DEX `string_data_item` 的 ULEB128 长度前缀。按「改规则 = 改版本」纪律修复并 bump 至 **0.1.4**，
本实验用**完全相同的协议与固定条件**复测，只让规则包版本变化，用于给出前后差异。

**设置**：同 `docs/experiment-protocol.md`；6 样本、每方法预热 1 次 + 计时 5 轮、只跑 `R-CODE-01`、
解码缓存复用、通道 B 未启用、零网络。输出 `review/exp_datasource_ab_v014.json`；
0.1.3 的 `review/exp_datasource_ab.json` 保留不改写。

**前后对照**：

| 指标 | 0.1.3（EXP-6） | 0.1.4（EXP-7） |
|------|-----------------|-----------------|
| A 组检出样本 | 1/6 | 1/6 |
| B 组检出样本 | **0/6** | **1/6** |
| 样本级检出一致 | 5/6 | **6/6** |
| bad03 B 组命中 | 0 | 1（`classes.dex#type[Ldalvik/system/DexClassLoader;]`，上限「待复核」） |
| bad03 `exact_membership` | False | **True** |
| A 组耗时中位（跨样本） | 78.787 ms | 78.282 ms |
| B 组耗时中位（跨样本） | 25.944 ms | 28.242 ms |
| 84 判点一致性 | 84/84 | **84/84**（`review/truth_result_0_1_4.json`，与 0.1.3 成绩单逐字节一致） |
| 单元测试 | 38 全过 | **46 全过**（新增 8 个 OBS-5 回归用例） |

**逐次数据（0.1.4；A 命中/中位 ms · B 命中/中位 ms）**：
bad01 0/78.342 · 0/24.917；bad02 0/77.384 · 0/24.950；**bad03 3/78.222 · 1/24.558**；
bad04 0/77.301 · 0/31.539；good01 0/94.938 · 0/31.535；good02 0/93.594 · 0/33.065。
6 个样本 `hits_stable_across_rounds = true`。

**结论**：

1. 修复后弱模式在唯一正例给出 1 条弱证据命中，档位上限仍为「待复核」，5 个安静点无新增误报；
   实验 6 的假设（同一检出结论、只牺牲证据强度）在 0.1.4 上成立。
2. 正常路径结论完全不变：84/84、硬错 0、噪声 0，新旧成绩单逐字节一致；单测 46 全过。
   影响面被限制在 `dexscan` 数据层与 `smali_src` 不可用的降级路径。
3. 耗时在两次运行间有正常波动（B 组中位 25.944 → 28.242 ms），**不作为修复带来的性能结论**；
   本实验不比较跨批次绝对耗时。

**边界**：同实验 6；修复未改变任何规则的检测点、误报口径或档位上限，仅修正数据层解析。
真值复算在不含 `key.txt` 的影子副本中执行（B 通道自动降级），不联网、不写 `evidence/`。
